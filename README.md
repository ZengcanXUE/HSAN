# HSAN
HSAN：融合超图高阶关联与全局感知的学生课堂行为识别方法

### 实验环境设置:
本实验在高性能计算环境中进行，硬件平台配置如下：操作系统为Ubuntu 20.04.6 LTS，CPU为Intel(R) Xeon(R) Platinum 12 vCPU，GPU为NVIDIA vGPU-32GB，内存90 GB。深度学习框架采用PyTorch 2.4.1，CUDA版本为12.1，开发语言为Python 3.8.20。

### 超参数设置: 
输入图像分辨率统一调整为640×640像素，以确保足够的细节信息用于小目标和细微行为检测。训练轮数设为300个epoch，使模型能够充分收敛；批次大小设为52，以在显存允许范围内最大化利用GPU并行计算能力。优化器选用随机梯度下降（SGD），初始学习率设为0.01，最终学习率因子为0.01，动量参数为0.937，权重衰减为0.0005。为增强模型的泛化能力，训练过程中采用Mosaic数据增强策略，并在最后10个epoch关闭以稳定收敛。HSWM模块的窗口大小设置为8，移位窗口偏移量为4。所有模型均从零开始训练，未使用任何预训练权重，以确保对比的公平性。
